# 学習リンク集（QR表示）

小学校の職員が、教科ごとにおすすめのサイトを持ち寄って共有し、
授業中に**電子黒板から QR コードを大きく出して、子どものタブレットで読み取らせる**ためのツールです。

- データは **Google スプレッドシート**に保管します
- 追加・編集は**職員共通の合い言葉**、削除は**管理者パスワード**
- 画面は **GitHub Pages** で配信する単純な HTML です（サーバー不要）
- 子どものタブレットはこのツールを開きません。**QR を読んで目的のサイトへ直行**します

## 画面の流れ

```
教科をえらぶ  →  一覧から「QR」を押す  →  全画面に QR が出る
```

学年（1〜6年）での絞り込みと、サイト名・メモを対象にしたキーワード検索ができます。

## 導入手順

所要 15 分ほどです。

### 1. スプレッドシートを作る

Google ドライブで新しいスプレッドシートを作り、分かりやすい名前を付けます
（例：`学習リンク集データ`）。

### 2. Apps Script を入れる

1. そのスプレッドシートで **拡張機能 → Apps Script** を開く
2. 最初から入っているコードをすべて消し、[`Code.gs`](Code.gs) の中身を貼り付けて保存
3. 関数の一覧から **`セットアップ`** を選んで実行（初回は承認を求められます）
   - `links` / `subjects` / `log` の3シートが作られます
   - 教科は `subjects` シートで自由に増減できます

### 3. 合い言葉を登録する

Apps Script の **プロジェクトの設定（歯車）→ スクリプト プロパティ** で、次の2つを追加します。

| プロパティ | 中身 |
|---|---|
| `EDIT_PASSWORD` | 職員共通の合い言葉（追加・編集に使う） |
| `ADMIN_PASSWORD` | 管理者パスワード（削除に使う） |

**このパスワードはスプレッドシート側にだけ置きます。公開される HTML には一切書きません。**

### 4. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ**
2. 種類は **ウェブアプリ**
3. **次のユーザーとして実行： 自分**
4. **アクセスできるユーザー： 全員**
5. デプロイして、表示された URL（`https://script.google.com/macros/s/……/exec`）を控える

> 「全員」にする必要があります。GitHub Pages は別ドメインなので、
> 「Google アカウントを持つ全員」にすると画面から呼び出せません。
> 書き込みは合い言葉で守ります。

### 5. 画面をつなぐ

`index.html` の先頭近くにある行を、控えた URL に書き換えます。

```js
var DEFAULT_API_URL = "";   // ← ここに /exec の URL を貼る
```

書き換えた `index.html` を GitHub にアップロードすれば、
先生は**何の設定もせず**にページを開くだけで使えます。

（書き換える前でも、ページを開いたときに出る「はじめの設定」画面に URL を貼れば、
その端末だけで試せます。`?api=…` を URL に付けても同じです。）

### 6. 中身を先に入れておく

**空のまま職員に配らないでください。** 空のリンク集は埋まりません。
自分がふだん使っているサイトを 30〜50 件、先に入れてから配ります。
`links` シートに直接貼り付けるのがいちばん早いです。

| 列 | 中身 |
|---|---|
| id | 何でもよい重複しない文字列（`a1`, `a2` … でも可） |
| サイト名 / URL / 教科 | 必須 |
| 学年 | `3` や `3,4` のように半角カンマ区切り。全学年は `1,2,3,4,5,6` |
| ひとことメモ | 任意。検索の対象になります |
| 追加した人 / 追加日時 / 更新日時 | 空でも可 |
| 表示 | `TRUE`（空欄でも表示されます） |

## 他校で使う場合

このリポジトリをフォークし、上の手順で**自分の学校のスプレッドシートと GAS** を用意して、
`index.html` の `DEFAULT_API_URL` を自分の URL に書き換えてください。
書き換えないと、他校のデータに接続してしまいます。

## 運用のメモ

- **削除は行を消しません。** 「表示」列が `FALSE` になるだけなので、
  誤って消してもスプレッドシートで `TRUE` に戻せます
- 誰がいつ何をしたかは `log` シートに残ります
- 追加した人の名前はスプレッドシートに記録されますが、**公開画面には出ません**
- URL が長いと QR の目が細かくなり、教室後方から読み取りにくくなります。
  登録画面で文字数に応じた注意が出ます
- リンク切れの自動チェックは入れていません。気づいた人が編集して直す運用です

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面のすべて（HTML / CSS / JavaScript） |

| `Code.gs` | Google Apps Script 側の API |
